# เกมบนเครื่องบิน (offline-flight-games)

เว็บเกมแบบไม่ต้องใช้อินเทอร์เน็ต (PWA) สำหรับมือถือ Android + Chrome — เล่นคนเดียว และเล่น 2 คนบนเครื่องเดียว
เขียนด้วย HTML + CSS + JavaScript ล้วน ไม่มีขั้นตอน build ไม่มี npm ไม่โหลดอะไรจากเว็บอื่น

- **เล่นคนเดียว:** 2048 · ซูโดกุ · หาระเบิด · โซลิแทร์ · ฟรีเซลล์ · สไปเดอร์ · บล็อกเติมแถว · เทน้ำเรียงสี · จับคู่ไพ่ความจำ · ไฟว์ไดซ์ · ภาพปริศนาเติมช่อง · หอบังคับการบิน · งู
  (จับคู่ไพ่ความจำ + ไฟว์ไดซ์ + หอบังคับการบิน เล่น 2 คนผลัดกันได้ด้วย)
- **เล่น 2 คน (เครื่องเดียว ผลัดกันกด หรือนั่งหันหน้าเข้าหากัน):** โอเอ็กซ์ · หยอดเหรียญเรียง 4 · ลากเส้นปิดกล่อง (3×3 / 4×4 / 5×5) · หมากฮอสไทย · หมากขุม · โอเทลโล · โกโมกุ (15×15) · เรือรบ (ส่งเครื่องให้กัน มีจอบัง)
- **เล่นกับคอม:** ทุกเกม 2 คนข้างบน เลือกได้ในปุ่มตั้งค่า (รูปแถบเลื่อน) → "เล่นกับคอม" + ความยาก ง่าย / ยาก
- **เกมกระดานผจญภัย:** ชิงเมืองแดนมนตร์ — คุณ + คอม 1–2 ตัว หรือ 2 คน + คอม 1 ตัว (v6 · v7 เพิ่มแผนที่ที่ 2 · ไพ่เหตุการณ์ · อุปกรณ์ 4 ขั้น + เครื่องราง)
- **ปุ่ม ⓘ (วิธีเล่น)** บนแถบหัวของทุกเกม — อธิบายสั้น ๆ 3–5 ข้อเป็นภาษาไทย
- **หน้าแรกมี 2 แท็บ** (v6): **เล่นคนเดียว** (เกมคนเดียว + เกมที่เล่นกับคอมได้) · **เล่น 2 คน** — เกมที่ทำได้ทั้งสองแบบขึ้นทั้งสองแท็บ ·
  ในแท็บเรียงตามชื่อไทย (ก–ฮ) · จำแท็บล่าสุดไว้ · ตั้งค่าว่าเกมไหนอยู่แท็บไหนที่ `modes` ใน `shared/games.js`
- **ปุ่ม 📤 ส่งลิงก์ให้เพื่อน** (v7) ล่างสุดของหน้าแรก — ติดตั้งเป็นแอปแล้วไม่มีแถบที่อยู่ให้คัดลอก จึงมีปุ่มนี้: เปิดหน้าต่างแชร์ของเครื่อง → ถ้าไม่มี คัดลอกลิงก์ให้ → ถ้าคัดลอกไม่ได้ แสดงลิงก์ให้เลือกเอง (ลิงก์ตายตัวใน `shared/share.js`)

### เกม 2 คน — ใช้ร่วมกันทุกเกม

- แดง = คนฝั่งล่างจอ · ฟ้า = คนฝั่งบนจอ · ป้ายของคนที่ถึงตาจะมีกรอบสีของตัวเอง + ป้าย "ตาคุณ"
- สลับกันเริ่มทุกตา · นับสกอร์สะสมข้ามตา (ชนะ/เสมอ) · ปิดแอปแล้วกลับมาเล่นต่อได้
- ปุ่มตั้งค่า (รูปแถบเลื่อน บนแถบหัว): **"ป้ายชื่อคนฝั่งบน → กลับหัว"** สำหรับนั่งหันหน้าเข้าหากัน · ล้างสกอร์
- จบตาแล้ว แตะกระดานหรือปุ่มเริ่มใหม่ = เล่นตาต่อไป

### เล่นกับคอม (โอเอ็กซ์ · หยอดเหรียญ · ลากเส้น · หมากฮอส · หมากขุม · โอเทลโล · โกโมกุ)

- ตั้งค่า → โหมด **เล่นกับคอม** → ความยาก **ง่าย** (ชนะได้ไม่ยาก) / **ยาก** (คิดล่วงหน้า ใช้เวลาคิดไม่เกินราว 0.5 วินาทีต่อตา)
- คุณ = ฝั่งแดง (ล่าง) · คอม = ฝั่งฟ้า (บน) · ยังสลับกันเริ่มทุกตาเหมือนเดิม
- สกอร์แยกกัน 3 ชุด: เล่น 2 คน / กับคอมง่าย / กับคอมยาก · เปลี่ยนโหมดกลางตา จะถามก่อนล้างกระดาน
- คอมใช้กติกาชุดเดียวกับคน (หมากฮอส: ตามตั้งค่าบังคับกิน/ไม่บังคับ, กินต่อจนสุด, ฮอสลงติดตัวที่กิน) · กด "ขอเสมอ" คอมจะตัดสินเอง (ยอมเมื่อไม่ได้เปรียบ)
- ปิดแอปตอนคอมกำลังคิด → เปิดกลับมาคอมเดินต่อให้เอง

### โอเทลโล · โกโมกุ

- **โอเทลโล:** 8×8 กติกามาตรฐาน · จุดสีเหลือง = ช่องที่ลงได้ · ไม่มีช่องลง = ข้ามตาให้เอง (ขึ้นข้อความบอก) · ทั้งสองฝ่ายลงไม่ได้ = จบ นับเม็ด
- **โกโมกุ:** 15×15 วางบนจุดตัด · เรียง 5 เม็ดขึ้นไป = ชนะ (แบบอิสระ) · กันแตะพลาดบนจอเล็ก: **แตะครั้งแรก = เม็ดจาง + เส้นเล็ง, แตะจุดเดิมอีกครั้ง = วาง** (ปิดได้ในตั้งค่า "แตะครั้งเดียว") · กระดานกว้างเกือบเต็มจอ (~25px ต่อจุดบนจอ 375px)

### เกมชุด v4 (เพิ่ม 2026-09-26)

- **ฟรีเซลล์:** กติกามาตรฐาน · เลขเกม 1–32000 แจกแบบเดียวกับ FreeCell ทั่วไป (พิมพ์เลขเดิมเพื่อเล่นซ้ำได้ · ไม่สุ่มได้เกม #11982 ที่ไม่มีทางชนะ) · ย้ายหลายใบได้ตามช่องพัก/แถวว่าง · ไพ่ที่ขึ้นกองได้แน่ ๆ ขึ้นเอง
- **สไปเดอร์:** 1 ดอก / 2 ดอก / 4 ดอก · แจกเพิ่มได้ 5 รอบ (ต้องไม่มีแถวว่าง) · ครบ K→A ดอกเดียวกันเก็บเอง
- **บล็อกเติมแถว:** กระดาน 8×8 · ชิ้นละ 3 ชิ้น ลากขึ้นไปวาง (ชิ้นลอยเหนือนิ้ว) · เต็มแถวนอน/ตั้งแล้วหาย · หมุนชิ้นไม่ได้
- **เทน้ำเรียงสี:** ด่านสร้างจากเลขด่าน (ด่านเดิมเหมือนเดิมทุกครั้ง) และผ่านตัวแก้แล้วว่ามีทางแก้ · 3 สีที่ด่าน 1 → 12 สีตั้งแต่ด่าน 19 · ย้อน / ใบ้ / เลือกด่านที่เคยผ่าน
- **จับคู่ไพ่ความจำ:** คนเดียว (นับครั้ง + เวลา) หรือ 2 คน (ได้คู่ = เปิดต่อ) · 4×4 / 4×6 / 6×6 · ภาพ 20 แบบวาดด้วยโค้ด
- **ไฟว์ไดซ์:** เต๋า 5 ลูก 13 ช่อง ทอยได้ 3 ครั้งต่อตา · โบนัสบน +35 (ถึง 63) · ไฟว์ไดซ์ซ้ำ +100 (กติกาโจ๊กเกอร์แบบบังคับ) · คนเดียว หรือ 2 คน
- **ภาพปริศนาเติมช่อง (nonogram):** 38 ภาพ (5×5 ×12 · 10×10 ×16 · 15×15 ×10) ทุกภาพคิดได้ด้วยตรรกะทีละแถว ไม่ต้องเดา (เทสตรวจทุกภาพ) · ถม / กากบาท · ลากนิ้วถมหลายช่อง · จำความคืบหน้าทุกภาพ
- **หมากขุม:** กติกาไทยจาก `docs/makkhum-thai-rules.md` (หัวข้อ "กติกาที่แนะนำ" + "สิ่งที่ตัวเกมทำจริง") · ฝั่งละ 7 หลุม หลุมละ 7 เม็ด · หยอดไปทางซ้าย ลงหัวเมืองตัวเอง ข้ามของอีกฝ่าย · หยอดต่อ · ตกหัวเมืองพอดี = เดินต่อ · ตายในแดนตัวเอง = กินแทน · เล่นเกมเดียวจบ (ยังไม่มีโหมดหลายรอบ "เมืองหม้าย")

### เกมชุด v5 (เพิ่ม 2026-09-26)

- **เรือรบ:** กระดาน 10×10 เรือ 5 ลำ (5·4·3·3·2) วางติดกันได้แต่ห้ามทับ · เรือสุ่มวางให้ก่อน แตะเรือ → แตะช่องที่จะให้หัวเรืออยู่ · ปุ่มหมุน / สุ่มใหม่
  - จอแสดงทีละกระดาน สลับ "ทะเลศัตรู / ทะเลของเรา"
  - ตั้งค่า: เล่น 2 คน / เล่นกับคอม (ง่าย = สุ่มยิง บางทีเล็งข้างช่องที่โดน · ยาก = ไล่ล่า + คำนวณความน่าจะเป็น) · กติกาการยิง **ผลัดกันนัดละครั้ง** (ค่าเริ่มต้น) / **ยิงโดนได้ยิงต่อ** (เปลี่ยนได้ทุกเมื่อ มีผลทันที)
  - 2 คน: มีจอบังเต็มจอทุกครั้งที่เปลี่ยนคน (ทั้งตอนวางเรือและตอนยิง) บอกว่าอีกฝ่ายเพิ่งยิงอะไรไป · ปิดแอปกลางเกม เปิดกลับมาจะขึ้นจอบังก่อนเสมอ
- **หอบังคับการบิน:** ลากนิ้วจากเครื่องบินเพื่อวาดเส้นทาง · ใหญ่ (ส้ม) → รันเวย์ยาว (เข้าจากปลายล่าง) · เล็ก (ฟ้า) → รันเวย์สั้น (เข้าจากปลายซ้าย) · เฮลิคอปเตอร์ (เขียว) → ลานจอด H
  - เส้นกลายเป็นเส้นทึบ = ลงจอดได้แน่ · วงแดง = ใกล้กันเกินไป · ชนกัน = จบรอบ · เครื่องมาถี่ขึ้นเรื่อย ๆ (8 วิ → 2.6 วิ ในราว 2.5 นาที)
  - คนเดียว (จำสถิติ) หรือ 2 คนผลัดกันคนละรอบ (เครื่องบินมาชุดเดียวกัน) แล้วเทียบกัน · สลับแอป/หมุนจอ = หยุดเอง · รอบที่เล่นค้างไม่ถูกบันทึก (เกมเรียลไทม์)

### เกมชุด v6 (เพิ่ม 2026-09-30)

- **ชิงเมืองแดนมนตร์:** เกมกระดานแนว RPG แฟนตาซี (คิดใหม่ทั้งหมด) เดินวนกระดาน 30 ช่อง ตีมอนสเตอร์ ยึดเมือง เก็บค่าผ่านทาง ลงทุนขยายเมือง
  - เลือกตอนเริ่ม: คอม 1 ตัว / คอม 2 ตัว / 2 คน + คอม (ส่งเครื่องให้กัน มีจอบัง) · ความยาว สั้น 15 / กลาง 22 / ยาว 30 รอบ
  - ต่อสู้แบบเลือกท่าพร้อมกัน (โจมตี / โจมตีแรง / ป้องกัน วนกันแบบเป่ายิ้งฉุบ) · ประลองผู้เล่นได้เฉพาะตอนหยุดช่องเดียวกัน ไม่เสียพลังชีวิต
  - บันทึกทุกการกระทำ ปิดแอปกลางเกมแล้วเปิดมา "เล่นต่อ" ได้ · กติกาเต็ม + ผลจำลองสมดุล: `docs/realm-rules.md`

### ชิงเมืองแดนมนตร์ v7 (2026-09-30)

- **2 แผนที่:** แดนมนตร์ (30 ช่อง 10 เมือง) · หมู่เกาะหิ่งห้อย (24 ช่อง 7 เมือง วนไว) — เลือกตอนเริ่มเกม · เซฟเก่าเปิดเล่นต่อได้บนกระดานฉบับเดิม
- **ศาลาเสี่ยงทาย:** ไพ่เหตุการณ์ 16 ใบ (ดี 10 · ร้าย 6 มีเพดาน) · ถุงเงินรวมเข้ากับหีบสมบัติ (ได้เงินหรือของ อย่างละครึ่ง)
- **ร้านค้า:** อาวุธ/เกราะ 4 ขั้น · เครื่องราง 4 แบบ (ช่องที่สาม) · ของใช้ใหม่: ระเบิด · รองเท้า (ทอย 2 ลูก) · ยันต์กันเคราะห์
- **ขยายเมืองต้องสู้ชนะหัวหน้าผู้เฝ้าก่อนทุกระดับ** · ประลองชนะได้ 20% · แพ้การต่อสู้เสีย 15%

### ขอบล่างจอ (แก้ปุ่มล่างโดนแถบของมือถือบัง — v5)

Chrome บน Android วาดหน้าเว็บลอดใต้แถบปุ่ม/ขีดปัดด้านล่าง และบอกความสูงแถบผ่าน `env(safe-area-inset-bottom)` ·
แต่ตอนเปิดเป็นแอปที่ติดตั้งแล้ว บางเครื่องได้ค่า 0 → ปุ่มแถวล่างสุดของทุกเกมโดนบัง ·
แก้ที่ `shared/base.css` (ตัวแปร `--fg-safe-bottom`) + `shared/app.js` (เดาความสูงเผื่อให้เองเมื่อเปิดแบบแอปบน Android) ·
ถ้ายังโดนบัง: หน้าแรก → ปุ่ม **ขอบล่างจอ** → เลือก กลาง / มาก

### หมากฮอสไทย — กติกาที่ใช้

ตาม `docs/makhos-thai-rules.md` + ที่เจ้าของเคาะ 2026-09-26: เบี้ยเดิน/กินไปข้างหน้าทีละช่อง ·
**บังคับกิน** (มีทางกินต้องกิน ไม่มีเป่า) — เปลี่ยนเป็น "ไม่บังคับกิน" ได้ในตั้งค่า · กินต่อได้ต้องกินต่อ ·
หลายทางกินเลือกได้อิสระ · ถึงแถวสุดท้าย = ฮอส และจบตาทันที · **ฮอสเดินไกลได้ แต่กินแล้วต้องลงช่องที่ติดหลังตัวที่ถูกกิน** ·
เสมอ = ปุ่ม "ขอเสมอ" (อีกฝ่ายกดตกลง) หรือตำแหน่งเดิมวนซ้ำ 3 ครั้ง · ปุ่มรูปหนังสือบนแถบหัว = แผ่นกติกาภาษาไทย

เทสกติกา + คอม (ไม่ต้องใช้เบราว์เซอร์ ต้องมี Node.js) — รันทุกไฟล์ทีเดียว:

```text
node tests/run-all.js
```

(หรือรันทีละไฟล์ เช่น `node tests/othello-engine.test.js` — `node tests/*.test.js` จะรันแค่ไฟล์แรก เพราะ node รับทีละไฟล์)

ไฟล์ `tests/` ไม่ได้อยู่ในรายการเก็บออฟไลน์ของแอป

## เพิ่มเกมใหม่

1. สร้างโฟลเดอร์ `games/<id>/` มี `index.html` + `style.css` + `game.js`
   (ก๊อปหัวไฟล์ `index.html` จากเกมที่มีอยู่ได้เลย — ทุกหน้าใช้ `../../shared/...` และ `data-root="../../"`)
2. เพิ่ม 1 แถวใน `GAMES` ที่ `shared/games.js` เช่น
   `{ id: 'xo', title: 'โอเอ็กซ์', blurb: 'เล่น 2 คนบนเครื่องเดียว', players: 2, modes: ['solo', 'duo'] }`
   - `modes` = แท็บที่เกมขึ้นบนหน้าแรก: `'solo'` เล่นคนเดียว (รวมเล่นกับคอม) · `'duo'` เล่น 2 คน · ทำได้ทั้งสองแบบใส่ทั้งคู่ (เทส `tests/hub-tabs.test.js` เช็คว่าทุกเกมอยู่อย่างน้อย 1 แท็บ)
   - ไฟล์ของเกมจะถูกใส่ในรายการเก็บออฟไลน์ให้อัตโนมัติ ถ้ามีไฟล์อื่นนอกจาก 3 ไฟล์หลัก ให้ใส่ `files: ['index.html','style.css','game.js','ภาพ.png']`
   - ไอคอนเล็กหน้าแรก: เพิ่มใน `GLYPHS` ที่ `shared/hub.js` (ถ้าไม่เพิ่ม จะใช้ตัวอักษรแรกของชื่อเกมแทน)
   - วิธีเล่น (ปุ่ม ⓘ): ใส่ `howto: ['ข้อ 1', 'ข้อ 2', ...]` ในแถวเดียวกัน แล้วในหน้าเกมโหลด `../../shared/games.js`
     และวางปุ่ม `<button type="button" class="icon-btn" data-howto="<id>" data-icon="info" aria-label="วิธีเล่น"></button>` เป็นปุ่มแรกใน `bar__actions`
   - เกม 2 คนที่อยากมีโหมดคอม: `FGDuo.create({ ..., ai: true })` แล้วใช้ `duo.isCPU(p)` / `duo.cpuMove(คิด, เดิน)` (ดูตัวอย่างใน games/ox/game.js)
3. เพิ่มเลข `CACHE_VERSION` ใน `sw.js` (ดูหัวข้อถัดไป)

## อัปเดตเวอร์ชัน (สำคัญ)

แก้ไฟล์ไหนก็ตามแล้วจะส่งขึ้นเว็บ → เปิด `sw.js` แก้บรรทัด

```js
const CACHE_VERSION = 'v7';   // ตอนนี้ v7 (ชิงเมืองแดนมนตร์ v7 + ปุ่มส่งลิงก์) → รอบหน้าเปลี่ยนเป็น 'v8', 'v9', ... ทุกครั้ง
```

ถ้าไม่เปลี่ยน มือถือที่เคยเปิดไว้แล้วอาจยังใช้ไฟล์เก่าอยู่
เมื่อเปลี่ยนแล้ว มือถือจะขึ้นแถบ **"มีเวอร์ชันใหม่ — แตะเพื่อรีโหลด"** (เกมที่เล่นค้างอยู่ไม่หาย เพราะบันทึกทุกตา)

## ขึ้น GitHub Pages

1. สร้าง repo ชื่อ `offline-flight-games` แล้วเอาไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ branch `main` (ไฟล์ `index.html` ต้องอยู่ชั้นบนสุดของ repo)
2. ใน repo: Settings → Pages → Source = "Deploy from a branch" → Branch = `main` / `(root)` → Save
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/offline-flight-games/`

ทุกลิงก์ในโปรเจกต์เป็นแบบ relative (ไม่มี `/` นำหน้า) จึงวางใต้ subpath แบบนี้ได้เลย
ถ้าต้องการทดสอบในเครื่อง: `python -m http.server 8000` ในโฟลเดอร์นี้ แล้วเปิด `http://localhost:8000/`

## เช็คลิสต์ก่อนขึ้นเครื่อง (10 ต.ค. 2026)

ทำตอนที่ยังมีเน็ต (ที่บ้าน / สนามบิน):

1. เปิดลิงก์ด้วย **Chrome** บนมือถือ รอจนหน้าแรกขึ้นสีเขียว **"พร้อมเล่นออฟไลน์ ✓"**
2. กดเมนู ⋮ ของ Chrome → **"ติดตั้งแอป"** หรือ **"เพิ่มลงในหน้าจอหลัก"** (หรือกดปุ่ม "ติดตั้งลงเครื่อง" ท้ายหน้าแรก ถ้ามี)
3. **เปิดโหมดเครื่องบิน** (ปิด Wi-Fi ด้วย) แล้วเปิดแอปจากไอคอนบนหน้าจอ
4. เข้าไป **เปิดทุกเกมอย่างน้อย 1 ครั้ง** เล่นสัก 2–3 ตา ให้แน่ใจว่าขึ้นครบ
5. ปิดโหมดเครื่องบินได้ตามปกติ — ไฟล์ยังอยู่ในเครื่อง

ข้อควรระวัง: อย่ากด "ล้างข้อมูลเว็บไซต์ / ล้างแคช" ของ Chrome ก่อนบิน (จะลบไฟล์ออฟไลน์ + สถิติทิ้ง) ถ้าเผลอล้าง ให้ต่อเน็ตแล้วเปิดใหม่ 1 ครั้ง
