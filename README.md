# เกมบนเครื่องบิน (offline-flight-games)

เว็บเกมแบบไม่ต้องใช้อินเทอร์เน็ต (PWA) สำหรับมือถือ Android + Chrome — เล่นคนเดียว และเล่น 2 คนบนเครื่องเดียว
เขียนด้วย HTML + CSS + JavaScript ล้วน ไม่มีขั้นตอน build ไม่มี npm ไม่โหลดอะไรจากเว็บอื่น

- **เล่นคนเดียว:** 2048 · ซูโดกุ · หาระเบิด · โซลิแทร์ · งู
- **เล่น 2 คน (เครื่องเดียว ผลัดกันกด หรือนั่งหันหน้าเข้าหากัน):** โอเอ็กซ์ · หยอดเหรียญเรียง 4 · ลากเส้นปิดกล่อง (3×3 / 4×4 / 5×5) · หมากฮอสไทย · โอเทลโล · โกโมกุ (15×15)
- **เล่นกับคอม:** ทุกเกม 2 คนข้างบน เลือกได้ในปุ่มตั้งค่า (รูปแถบเลื่อน) → "เล่นกับคอม" + ความยาก ง่าย / ยาก
- **ปุ่ม ⓘ (วิธีเล่น)** บนแถบหัวของทุกเกม — อธิบายสั้น ๆ 3–5 ข้อเป็นภาษาไทย

### เกม 2 คน — ใช้ร่วมกันทุกเกม

- แดง = คนฝั่งล่างจอ · ฟ้า = คนฝั่งบนจอ · ป้ายของคนที่ถึงตาจะมีกรอบสีของตัวเอง + ป้าย "ตาคุณ"
- สลับกันเริ่มทุกตา · นับสกอร์สะสมข้ามตา (ชนะ/เสมอ) · ปิดแอปแล้วกลับมาเล่นต่อได้
- ปุ่มตั้งค่า (รูปแถบเลื่อน บนแถบหัว): **"ป้ายชื่อคนฝั่งบน → กลับหัว"** สำหรับนั่งหันหน้าเข้าหากัน · ล้างสกอร์
- จบตาแล้ว แตะกระดานหรือปุ่มเริ่มใหม่ = เล่นตาต่อไป

### เล่นกับคอม (โอเอ็กซ์ · หยอดเหรียญ · ลากเส้น · หมากฮอส · โอเทลโล · โกโมกุ)

- ตั้งค่า → โหมด **เล่นกับคอม** → ความยาก **ง่าย** (ชนะได้ไม่ยาก) / **ยาก** (คิดล่วงหน้า ใช้เวลาคิดไม่เกินราว 0.5 วินาทีต่อตา)
- คุณ = ฝั่งแดง (ล่าง) · คอม = ฝั่งฟ้า (บน) · ยังสลับกันเริ่มทุกตาเหมือนเดิม
- สกอร์แยกกัน 3 ชุด: เล่น 2 คน / กับคอมง่าย / กับคอมยาก · เปลี่ยนโหมดกลางตา จะถามก่อนล้างกระดาน
- คอมใช้กติกาชุดเดียวกับคน (หมากฮอส: ตามตั้งค่าบังคับกิน/ไม่บังคับ, กินต่อจนสุด, ฮอสลงติดตัวที่กิน) · กด "ขอเสมอ" คอมจะตัดสินเอง (ยอมเมื่อไม่ได้เปรียบ)
- ปิดแอปตอนคอมกำลังคิด → เปิดกลับมาคอมเดินต่อให้เอง

### โอเทลโล · โกโมกุ

- **โอเทลโล:** 8×8 กติกามาตรฐาน · จุดสีเหลือง = ช่องที่ลงได้ · ไม่มีช่องลง = ข้ามตาให้เอง (ขึ้นข้อความบอก) · ทั้งสองฝ่ายลงไม่ได้ = จบ นับเม็ด
- **โกโมกุ:** 15×15 วางบนจุดตัด · เรียง 5 เม็ดขึ้นไป = ชนะ (แบบอิสระ) · กันแตะพลาดบนจอเล็ก: **แตะครั้งแรก = เม็ดจาง + เส้นเล็ง, แตะจุดเดิมอีกครั้ง = วาง** (ปิดได้ในตั้งค่า "แตะครั้งเดียว") · กระดานกว้างเกือบเต็มจอ (~25px ต่อจุดบนจอ 375px)

### หมากฮอสไทย — กติกาที่ใช้

ตาม `docs/makhos-thai-rules.md` + ที่เจ้าของเคาะ 2026-09-26: เบี้ยเดิน/กินไปข้างหน้าทีละช่อง ·
**บังคับกิน** (มีทางกินต้องกิน ไม่มีเป่า) — เปลี่ยนเป็น "ไม่บังคับกิน" ได้ในตั้งค่า · กินต่อได้ต้องกินต่อ ·
หลายทางกินเลือกได้อิสระ · ถึงแถวสุดท้าย = ฮอส และจบตาทันที · **ฮอสเดินไกลได้ แต่กินแล้วต้องลงช่องที่ติดหลังตัวที่ถูกกิน** ·
เสมอ = ปุ่ม "ขอเสมอ" (อีกฝ่ายกดตกลง) หรือตำแหน่งเดิมวนซ้ำ 3 ครั้ง · ปุ่มรูปหนังสือบนแถบหัว = แผ่นกติกาภาษาไทย

เทสกติกา + คอม (ไม่ต้องใช้เบราว์เซอร์ ต้องมี Node.js) — รันทุกไฟล์ทีเดียว:

```text
node tests/run-all.js
```

(หรือรันทีละไฟล์ เช่น `node tests/othello-engine.test.js` — `node tests/*.test.js` จะรันแค่ไฟล์แรก เพราะ node รับทีละไฟล์)

ไฟล์ `tests/` ไม่ได้อยู่ในรายการเก็บออฟไลน์ของแอป

## โครงไฟล์

```text
index.html              หน้าแรก (รายการเกม + สถานะพร้อมเล่นออฟไลน์)
manifest.webmanifest    ข้อมูลแอปสำหรับติดตั้งลงหน้าจอ
sw.js                   service worker เก็บทุกไฟล์ไว้ในเครื่อง (มี CACHE_VERSION)
shared/
  games.js              รายชื่อเกม + รายการไฟล์ที่ต้องเก็บออฟไลน์ (ใช้ทั้งหน้าแรกและ sw.js)
  tokens.css            สี/ฟอนต์/ระยะ ทั้งหมด (ธีมมืด + ธีมสว่าง)
  base.css              แถบหัว ปุ่ม หน้าต่างถาม ฯลฯ ที่ใช้ร่วมกัน
  app.js                บันทึกข้อมูล, ธีม, ลงทะเบียน SW, แถบอัปเดต, ปัดนิ้ว, ไอคอน
  hub.css / hub.js      เฉพาะหน้าแรก
  duo.css / duo.js      ของใช้ร่วมเกม 2 คน (ป้ายผู้เล่นบน/ล่าง, ตาใคร, สกอร์, หน้าตั้งค่า, โหมดเล่นกับคอม)
icons/                  ไอคอนแอป (svg + png 192/512 + maskable)
games/<ชื่อเกม>/         เกมละโฟลเดอร์: index.html + style.css + game.js
games/makhos/engine.js  กติกาหมากฮอสไทยล้วน ๆ (ใช้ทั้งในหน้าเกมและในเทส)
games/othello/engine.js · games/gomoku/engine.js   กติกา + คอม ของโอเทลโล / โกโมกุ
games/<ox|connect4|dots|makhos>/ai.js   คอมของเกมนั้น (ใช้ทั้งในหน้าเกมและในเทส)
tests/                  เทสกติกา + คอม (รันด้วย node — ไม่ถูกเก็บออฟไลน์) · run-all.js = รันทุกไฟล์
docs/image-prompts.md   prompt สำหรับทำภาพใน ChatGPT (ทางเลือก ถ้าอยากอัปเกรดภาพ)
docs/makhos-thai-rules.md  กติกาหมากฮอสไทยที่ค้นมา + แหล่งอ้างอิง
```

## เพิ่มเกมใหม่

1. สร้างโฟลเดอร์ `games/<id>/` มี `index.html` + `style.css` + `game.js`
   (ก๊อปหัวไฟล์ `index.html` จากเกมที่มีอยู่ได้เลย — ทุกหน้าใช้ `../../shared/...` และ `data-root="../../"`)
2. เพิ่ม 1 แถวใน `GAMES` ที่ `shared/games.js` เช่น
   `{ id: 'xo', title: 'โอเอ็กซ์', blurb: 'เล่น 2 คนบนเครื่องเดียว', players: 2 }`
   - `players: 2` = ขึ้นในหัวข้อ "เล่น 2 คน" เอง (ข้อความ "เร็ว ๆ นี้" จะหายไปเอง)
   - ไฟล์ของเกมจะถูกใส่ในรายการเก็บออฟไลน์ให้อัตโนมัติ ถ้ามีไฟล์อื่นนอกจาก 3 ไฟล์หลัก ให้ใส่ `files: ['index.html','style.css','game.js','ภาพ.png']`
   - ไอคอนเล็กหน้าแรก: เพิ่มใน `GLYPHS` ที่ `shared/hub.js` (ถ้าไม่เพิ่ม จะใช้ตัวอักษรแรกของชื่อเกมแทน)
   - วิธีเล่น (ปุ่ม ⓘ): ใส่ `howto: ['ข้อ 1', 'ข้อ 2', ...]` ในแถวเดียวกัน แล้วในหน้าเกมโหลด `../../shared/games.js`
     และวางปุ่ม `<button type="button" class="icon-btn" data-howto="<id>" data-icon="info" aria-label="วิธีเล่น"></button>` เป็นปุ่มแรกใน `bar__actions`
   - เกม 2 คนที่อยากมีโหมดคอม: `FGDuo.create({ ..., ai: true })` แล้วใช้ `duo.isCPU(p)` / `duo.cpuMove(คิด, เดิน)` (ดูตัวอย่างใน games/ox/game.js)
3. เพิ่มเลข `CACHE_VERSION` ใน `sw.js` (ดูหัวข้อถัดไป)

## อัปเดตเวอร์ชัน (สำคัญ)

แก้ไฟล์ไหนก็ตามแล้วจะส่งขึ้นเว็บ → เปิด `sw.js` แก้บรรทัด

```js
const CACHE_VERSION = 'v3';   // ตอนนี้ v3 (รอบโอเทลโล · โกโมกุ · เล่นกับคอม · ปุ่ม ⓘ) → รอบหน้าเปลี่ยนเป็น 'v4', 'v5', ... ทุกครั้ง
```

ถ้าไม่เปลี่ยน มือถือที่เคยเปิดไว้แล้วอาจยังใช้ไฟล์เก่าอยู่
เมื่อเปลี่ยนแล้ว มือถือจะขึ้นแถบ **"มีเวอร์ชันใหม่ — แตะเพื่อรีโหลด"** (เกมที่เล่นค้างอยู่ไม่หาย เพราะบันทึกทุกตา)

## ขึ้น GitHub Pages

1. สร้าง repo ชื่อ `offline-flight-games` แล้วเอาไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ branch `main` (ไฟล์ `index.html` ต้องอยู่ชั้นบนสุดของ repo)
2. ใน repo: Settings → Pages → Source = "Deploy from a branch" → Branch = `main` / `(root)` → Save
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/offline-flight-games/`

ทุกลิงก์ในโปรเจกต์เป็นแบบ relative (ไม่มี `/` นำหน้า) จึงวางใต้ subpath แบบนี้ได้เลย
ถ้าต้องการทดสอบในเครื่อง: `python -m http.server 8000` ในโฟลเดอร์นี้ แล้วเปิด `http://localhost:8000/`

## เช็คลิสต์ก่อนขึ้นเครื่อง (10 ต.ค. 2026)

ทำตอนที่ยังมีเน็ต (ที่บ้าน / สนามบิน):

1. เปิดลิงก์ด้วย **Chrome** บนมือถือ รอจนหน้าแรกขึ้นสีเขียว **"พร้อมเล่นออฟไลน์ ✓"**
2. กดเมนู ⋮ ของ Chrome → **"ติดตั้งแอป"** หรือ **"เพิ่มลงในหน้าจอหลัก"** (หรือกดปุ่ม "ติดตั้งลงเครื่อง" ท้ายหน้าแรก ถ้ามี)
3. **เปิดโหมดเครื่องบิน** (ปิด Wi-Fi ด้วย) แล้วเปิดแอปจากไอคอนบนหน้าจอ
4. เข้าไป **เปิดทุกเกมอย่างน้อย 1 ครั้ง** เล่นสัก 2–3 ตา ให้แน่ใจว่าขึ้นครบ
5. ปิดโหมดเครื่องบินได้ตามปกติ — ไฟล์ยังอยู่ในเครื่อง

ข้อควรระวัง: อย่ากด "ล้างข้อมูลเว็บไซต์ / ล้างแคช" ของ Chrome ก่อนบิน (จะลบไฟล์ออฟไลน์ + สถิติทิ้ง) ถ้าเผลอล้าง ให้ต่อเน็ตแล้วเปิดใหม่ 1 ครั้ง

## เก็บข้อมูลอะไรไว้บ้าง

ทุกอย่างอยู่ใน `localStorage` ของเครื่อง (คีย์ขึ้นต้น `ffg:`) ไม่ส่งไปไหน:
สถิติ/เวลาดีที่สุด, เกมที่เล่นค้าง (2048 · ซูโดกุ · หาระเบิด · โซลิแทร์ · เกม 2 คนทั้ง 6 เกม), ธีมมืด/สว่าง, ความเร็วงู, แบบจั่วไพ่,
สกอร์สะสมของเกม 2 คน (แยกเล่น 2 คน / กับคอมง่าย / กับคอมยาก), โหมดเล่นกับคอม + ความยาก (แยกทีละเกม), ตั้งค่าป้ายกลับหัว,
ขนาดกระดานลากเส้น, กติกาบังคับกินของหมากฮอส, วิธีวางเม็ดโกโมกุ (แตะ 2 ครั้ง / ครั้งเดียว)
